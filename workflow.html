Arbetsprocess

Verktyg

Verktyg som används under utvecklingen är Node.js, Vite, Github Actions, Vite Plugin Image Optimizer och Vite Imagetools.

Node.js används för att hantera beroenden och möjliggöra användningen av de övriga verktygen som bygger på den.

Vite är ett modern byggvekrtyg och används för att strukturera, optimera och bunta projektet för publicering. Verktyget väljs eftersom det är lätt att använda, är effektiv, kompatibel med många moderna ramverk och har stöd för flera användbara insticksmoduler.

Vite Plugin Image Optimizer och Vite Image Tools är oberoende insticksmoduler för Vite. Den ena komprimerar bilder och den andra skapar responsiva bilder i olika format och dimensioner.

Webbplatsen publiceras till Github Pages med hjälp av ett arbetsflöde och Github Actions. Github Pages väljs för publicering eftersom plattformen tillåter versionshantering, automatisering och publicering av frontend-applikationer på en och samma plats, vilket underlättar utvecklingen.

Automatisering

Automatisering sker via Github Actions och ett arbetsflöde skrivet i dataserialiseringsspråket YAML. Skriptet startas när Git-grenen 'dev' respektive 'prod' uppdateras.

Först förbereds Github Pages-miljön. Därefter tas bort den gamla gh-pages-grenen där publiceringsfilerna ligger så att de gamla filerna inte står i konflikt med de nya.

Beroenden från package-lock.json installeras och projektet byggs med hjälp av Vite och slutligen publiceras till Github Pages från katalogen 'dist' där den Vite-optimerade projektversionen ligger.

När Vite bygger projeketet optimeras samtidigt alla bilder via insticksmodulerna. Här är ordningen av insticksmodulerna i vite.config.js-filen viktig, eftersom först kör Vite Imagetools och skapar responsiva bilder och strax efter komprimeras dessa med hjälp av Vite Plugin Image Optimizer.

Metod

Projektet skapas med hjälp av packethanteraren NPM och Vite via Node.js-miljön. Katalogerna och filerna struktureras och undersidorna utformas. Konfigurationerna görs för arbetsflödet och för Vite och publiceringen testas därefter. Sist sker CSS stilisering när alla vyer redan är utformade och funktionella.

Git-grenen 'dev' används för utvecklingen och slås sedan samman med 'prod'-grenen först när webbplatsen är redo för offentlig publicering.
